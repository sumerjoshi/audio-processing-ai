# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- GitHub Actions CI/CD workflows
- Pre-commit hooks for code quality
- Comprehensive testing setup
- Contributing guidelines
- Automated dependency updates

### Changed
- Restructured project to follow modern Python packaging standards
- Moved all modules to `src/audio_processing_ai/` structure
- Updated to use `uv` for faster dependency management
- Increased minimum Python version requirement to 3.9+

### Fixed
- Import paths for new package structure
- Dependency version conflicts

## [0.1.0] - 2024-09-22

### Added
- Initial release of Audio Processing AI
- AI-generated audio detection capabilities
- CNN14-based dual-head classification model
- Training and prediction scripts
- Audio preprocessing utilities
- Support for multiple audio formats (.mp3, .wav, .flac, .m4a)
- Music analysis features (genre, mood, tempo, etc.)
- Comprehensive CSV and Excel output generation
